# 2026-10-22 更新说明

本次以用户提供的 `KernelEvolve.zip` 作为当前源码版本，保留旧仓库的 Git 历史及 [v0.1.0 Release](https://github.com/sevenboom77/Kernel_Evolve/releases/tag/v0.1.0)。

## 与上一版的区别

| 内容 | 上一版 | 当前版本 |
|---|---|---|
| 项目交付 | 完整历史工程、捆绑的 AGH、演示和实验材料 | 可直接调用的算子、AGH 插件及本地评测器 |
| 算子入口 | `demo/sources/` | `operators/small_m/` 和 `operators/graph/` |
| 核心实现 | 原 Small-M 与 CSR 图聚合内核 | 两份实现逐字节一致；20 个 `kernel_lab` 文件也保持一致 |
| 直接复现 | 分散在历史脚本中 | 新增 `benchmarks/run.py`，统一计划、正确性与计时入口 |
| 任务范围 | 配置曾列出未随包提供的任务 | 配置与实际提供的 K12、K19 一致 |
| AGH 依赖 | 源码和运行时随工程存放 | 独立安装，通过本仓库的原生插件接入 |
| 图基准 | 历史真实图完整应用及相应对照 | 三组合成 CSR，比较融合聚合与 PyTorch gather + `index_add_` |

这次更新是交付整理与使用方式改进，没有修改两份 GPU 内核算法，也没有新增实测加速倍率。旧实验结果仍属于旧版本的实验条件，不能作为当前独立基准的重新测量结果。

## 对压缩包的必要修正

- 将插件 smoke 脚本中的旧任务 K03 改为本包已有的 K12，并更新脚本路径。
- 修复插件使用 `/` 拼接路径导致 Windows 合法候选目录被拒绝的问题，保留工作区边界检查。
- 将评测结果目录说明改为实际的 `artifacts/<run-id>/`。
- 补充图 API 的 CSR 输入与 schedule 复用前提，以及 AGH 版本、安装和工具调用返回路径。

## 验证范围

本次本地检查覆盖两个无需 GPU 的基准计划、Python 语法、K12/K19 任务契约加载、配置生成和插件的预算与路径回归测试。实际 GPU 正确性、计时及完整 AGH 模型运行需要另行在 Linux/CUDA 环境执行；本次未重新测量性能。
