# 公开仓库整理说明

本仓库基于 G004 KernelEvolve 原始源码交付包整理，保留 GPU 候选、评测器、任务、工具插件、应用实现与实验结果。公开目录在不改动候选计算逻辑和实验数值的前提下做了以下整理。

## 源码与下载附件

G031 原归档的 3,633 个文件直接展开为 `third_party/agnes-harness/`，内容绑定见 `third_party/AGH_SNAPSHOT.json`。G000、G014、G031 原源码 tar 与 ogbn-arxiv 数据归档通过 Release 提供，`release-assets.json` 同时保存下载文件与还原文件的 SHA256。获取脚本不会读取账户凭据。

原交付包中的预构建运行目录、个人报名材料、视频制作记录、旧打包清单和本地安装目录不进入 Git。当前构建与使用入口以仓库 README 和 SOURCE_INSTALL 为准。

## 运行记录中的路径

部分冻结日志、一个 SQLite 结果字段及一份开发计划出现原执行机的私人 home 用户名。公开副本将该路径段替换为 `USER`，未改候选代码、实验数值或原有源代码哈希标识。SQLite 已重新整理，原目录中的文件没有被覆盖。

[publication-redactions.json](publication-redactions.json) 记录这些文件的原始与公开 SHA256，不记录私人路径。`demo/review-manifest.json` 中对应公开文件的哈希和长度已经更新。其他历史报告中绑定的旧哈希仍用于说明原始实验，不应当作公开副本变更后的逐字节哈希。

## 结果与执行范围

工作台展示已保存记录。查看网页或通过源码校验，不会重新调用模型或启动 GPU 作业。GPU 复测需要按安装指南显式执行，并以当前设备实际结果为准。

仓库保留 K12、K19 任务包及 K12、图应用的独立复测入口。20 项任务对比来自保存的历史实验；完整重跑需补齐其他任务包。项目面向 RSI 的研究目标与当前工程结果分别说明。
